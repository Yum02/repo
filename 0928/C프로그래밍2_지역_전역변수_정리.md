## 1. 변수의 범위

- 변수는 **선언된 위치**에 따라 사용할 수 있는 범위(scope)가 정해진다.
- **지역 변수(local variable)**: 함수 안, 또는 블록(`{ }`) 안에서 선언한 변수
- **전역 변수(global variable)**: 함수 밖에서 선언한 변수. 파일 전체(모든 함수)에서 사용할 수 있다.

| 구분 | 선언 위치 | 사용 범위 |
|------|-----------|-----------|
| 지역 변수 | 함수/블록 안 | 선언된 블록 안 |
| 전역 변수 | 모든 함수 밖 | 선언 이후 프로그램 전체 |

> (PDF의 2, 3, 5쪽은 범위를 그린 그림이라 텍스트로 읽을 수 없었다. 위 표와 아래 7절의 이름 가리기 설명은 일반적인 내용을 보충한 것이다.)

## 2. 지역 변수의 범위

- 지역 변수는 **선언된 블록을 떠나면 사용할 수 없다.**

```c
void sub1(void)
{
    {
        int y;
        ...
    }
    y = 4;    // 오류! y는 안쪽 블록에서만 유효하다.
}
```

- 지역 변수는 **함수뿐 아니라 블록 안에서도** 선언할 수 있다.

```c
#include <stdio.h>
const double tax_rate = 0.05;    // 전역 (상수)

int main(void) {
    int income = 100;
    if (tax_rate > 0)
    {
        int tax;                 // 이 블록 안에서만 유효
        tax = income * tax_rate;
        income -= tax;
    }
    printf("실제 소득=%d \n", income);
    return 0;
}
```
전체 소스: `01_block_scope.c`

### 이름이 같은 변수 (보충)
- 서로 다른 함수의 지역 변수는 이름이 같아도 **완전히 다른 변수**이다.
- 전역 변수와 지역 변수의 이름이 같으면, 그 지역 변수가 있는 블록 안에서는 **지역 변수가 우선**한다.
- 이름을 겹치면 헷갈리므로 피하는 것이 좋다.

전체 소스: `07_shadowing.c` (보충 예제)

## 3. 지역 변수의 초기값과 생존 기간

### 초기값
- 지역 변수는 **자동으로 초기화되지 않는다.** 초기화하지 않으면 **쓰레기 값**을 가진다.

```c
#include <stdio.h>
int main(void)
{
    int temp;
    printf("temp = %d\n", temp);    // 쓰레기 값
}
```
PDF의 실행 결과: `temp = -858993460`
(Visual Studio 디버그 빌드는 초기화하지 않은 스택을 `0xCCCCCCCC` 로 채워서 이 값이 나온다. 최적화된 릴리스 빌드에서는 다른 값, 예를 들어 0이 나올 수도 있다. 어느 쪽이든 **값을 믿으면 안 된다.**)

전체 소스: `02_uninitialized_local.c`

### 생존 기간
- 지역 변수는 **블록에 들어갈 때 생성**되고, **블록을 벗어나면 소멸**한다.
- 그래서 함수를 다시 호출하면 지역 변수는 매번 새로 만들어진다.

```
{             ← 생성
    int x;
    ...
}             ← 소멸
```

## 4. 전역 변수의 초기값과 생존 기간

- 전역 변수는 **자동으로 0으로 초기화**된다.
- 전역 변수는 **프로그램이 시작될 때 생성**되고 **프로그램이 끝날 때까지** 유지된다.
- 모든 함수에서 접근할 수 있으므로, 함수 사이에서 값을 공유할 수 있다.

```c
#include <stdio.h>
int counter;          // 전역 변수. 초기값은 0

void sub1() { counter++; }
void sub2() { counter++; }

int main(void)
{
    sub1();
    sub2();
    printf("counter=%d\n", counter);    // counter=2
    return 0;
}
```
전체 소스: `03_global_counter.c`

| 구분 | 지역 변수 | 전역 변수 |
|------|-----------|-----------|
| 초기값 | 쓰레기 값 | 0 |
| 생성 | 블록 진입 시 | 프로그램 시작 시 |
| 소멸 | 블록 종료 시 | 프로그램 종료 시 |

## 5. 저장 유형 지정자 static

- 지역 변수 앞에 `static` 을 붙이면 **정적 지역 변수**가 된다.
- 정적 지역 변수는
  - 사용 범위는 **선언된 함수 안**(지역 변수)이지만,
  - 값은 **함수가 끝나도 사라지지 않고 유지**된다. (프로그램 끝까지 생존)
  - **한 번만** 초기화된다.
  - 초기값을 주지 않으면 0이다. (전역 변수와 같다.)
- 그냥 지역 변수는 **자동 지역 변수(auto)** 라고 한다.

```c
void sub(void)
{
    int auto_count = 0;             // 자동 지역 변수: 호출마다 0으로 초기화
    static int static_count = 0;    // 정적 지역 변수: 값이 유지됨
    auto_count++;
    static_count++;
    printf("auto_count=%d\n", auto_count);
    printf("static_count=%d\n", static_count);
}
```

`sub()` 를 3번 호출한 결과

```
auto_count=1
static_count=1
auto_count=1
static_count=2
auto_count=1
static_count=3
```
전체 소스: `04_static_local.c`

## 6. 핵심 예제: 저축 금액 누적하기

- 호출될 때마다 전달받은 숫자를 **정적 지역 변수**에 더하는 함수 `sum_it()` 를 작성한다.

```c
void sum_it(int money)
{
    static int sum = 0;    // 한 번만 초기화되고 값이 유지된다
    sum += money;
    printf("현재의 합계는 %d입니다 \n", sum);
}
```
`main()` 에서 `sum_it(0)` ~ `sum_it(4)` 를 호출하면 합계는 0, 1, 3, 6, 10 이 된다.

전체 소스: `05_sum_it.c`

## 7. 실습: 로그인 횟수 제한

제한된 횟수만큼 틀리면 로그인 시도를 막는 프로그램이다.

### 알고리즘
1. `while (1)` 반복
2. 사용자로부터 아이디를 입력받는다.
3. 사용자로부터 패스워드를 입력받는다.
4. 로그인 시도 횟수가 한도를 넘으면 프로그램을 종료한다.
5. 아이디와 패스워드가 일치하면 로그인 성공 메시지를 출력한다.
6. 일치하지 않으면 다시 시도한다.

### 핵심 포인트
- 시도 횟수 `try_count` 를 **정적 지역 변수**로 두어 `check()` 를 호출할 때마다 누적한다. (전역 변수를 쓰지 않고도 값을 유지할 수 있다.)
- 정답 아이디/비밀번호(`super_id`, `super_password`)도 `static` 으로 선언되어 있다.
- `#define LIMIT 3` 으로 한도를 정하고, 넘으면 `exit(1)` 로 프로그램을 끝낸다.
- 성공은 `SUCCESS`(1), 실패는 `FAIL`(2) 로 반환한다.

### 실행 결과 (PDF 예)
```
id: 1111
pass: 1111
id: 1111
pass: 1111
id: 1111
pass: 1111
횟수 초과
```

### 주의: 코드의 동작 (직접 확인함)
- `try_count++` 뒤에 `try_count >= LIMIT` 을 먼저 검사하므로, **3번째 시도는 맞게 입력해도 "횟수 초과"** 가 된다. 즉 실제로 쓸 수 있는 시도는 2번이다.
- `printf("id: ____\b\b\b\b")` 는 밑줄 4개를 찍고 `\b` 로 커서를 되돌려 입력칸처럼 보이게 하는 표현이다.

전체 소스: `06_login_limit.c`
