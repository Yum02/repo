## 1. 라이브러리 함수

- **라이브러리 함수(library function)**: 컴파일러가 미리 만들어서 제공하는 함수
- 직접 만들지 않고 `#include` 로 헤더를 포함해서 호출만 하면 된다.
- 주요 분야
  - 표준 입출력 (`stdio.h`)
  - 수학 연산 (`math.h`)
  - 문자열 처리 (`string.h`)
  - 시간 처리 (`time.h`)
  - 오류 처리
  - 데이터 검색과 정렬 (`stdlib.h`)

---

## 2. 난수 함수 rand()

- **난수(random number)**: 규칙성 없이 임의로 생성되는 수. 암호학, 시뮬레이션, 게임 등에서 필수적이다.
- `rand()`: 난수를 생성하는 함수 (`<stdlib.h>`)
  - **0부터 `RAND_MAX`까지**의 정수를 생성한다. (PDF의 실행 결과 기준 `RAND_MAX` = 32767)

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int i;
    for (i = 0; i < 6; i++)
        printf("%d ", rand());   // rand() - 난수 생성기
    return 0;
}
```
실행 결과 예: `41 18467 6334 26500 19169 15724`
(0에서 32767 사이의 정수로 생성됨)

## 3. 난수 범위 제한과 시드(srand)

### 범위 제한
- `%` 연산자로 범위를 제한한다.
- 1부터 45 사이: `1 + (rand() % 45)`
- 단, 이 상태로는 **실행할 때마다 항상 똑같은 난수**가 나온다. (예: `42 18 35 41 45 20`)

### 시드(seed)
- 매번 다르게 하려면 **시드(seed)** 를 다르게 해야 한다.
- `srand(time(NULL));` 이 시드를 만드는 가장 기본 형태이다.
- 시드는 **현재 시각**을 쓰는 것이 가장 일반적이다. 현재 시각은 실행할 때마다 다르기 때문이다.
- `time()` 을 쓰려면 `<time.h>` 가 필요하다.

```c
#include <stdlib.h>
#include <stdio.h>
#include <time.h>
#define MAX 45

int main(void)
{
    int i;
    srand(time(NULL));
    for (i = 0; i < 6; i++)
        printf("%d ", 1 + rand() % MAX);
    return 0;
}
```

| 함수 | 헤더 | 역할 |
|------|------|------|
| `rand()` | `stdlib.h` | 0 ~ `RAND_MAX` 난수 생성 |
| `srand(seed)` | `stdlib.h` | 난수 발생기 시드 설정 |
| `time(NULL)` | `time.h` | 현재 시각 반환 (시드용) |

## 5. 실습: 동전 던지기 게임

동전을 100번 던져서 앞면과 뒷면이 나온 횟수를 출력한다.

- `rand() % 2` 는 0 또는 1이다. → 0이면 뒷면, 1이면 앞면
- 동전 던지기는 사용자 함수 `coin_toss()` 로 분리하고 **함수 원형**을 먼저 선언한다.

```c
int coin_toss(void);   // 사용자 함수 원형

int coin_toss(void)
{
    int i = rand() % 2;
    if (i == 0)
        return 0;   // 뒷면
    else
        return 1;   // 앞면
}
```
전체 소스: `04_coin_toss.c`

## 6. 실습: 화면에 점 무작위로 찍기 (Windows GDI)

- 난수를 이용해서 화면에 점을 불규칙하게 그린다.
- 윈도우의 **GDI(Graphic Device Interface)** 함수 `SetPixel()` 을 사용한다. (Windows 전용, `<windows.h>`)
- `SetPixel(hdc, x, y, RGB(red, green, blue))`
  - x, y: `rand() % 300` → 0~299
  - red, green, blue: `rand() % 256` → 0~255
- GDI 그래픽에 필수인 두 변수
  - `HWND`: 윈도우 창의 핸들(번호)
  - `HDC`: GDI에서 폰트, 색상, 굵기, 출력 방법 등 모든 출력에 필요한 정보를 담는 구조체
- `GetForegroundWindow()` 로 창 핸들을, `GetWindowDC(hwnd)` 로 DC를 얻는다.

전체 소스: `05_random_pixels.c`

## 7. 수학 라이브러리 함수

- 헤더: `<math.h>`
- (PDF의 함수 목록 슬라이드는 그림이라 텍스트로 읽을 수 없었다. 아래 표는 **일반적으로 자주 쓰는 함수를 보충**한 것이다.)

| 함수 | 설명 |
|------|------|
| `sin(x)`, `cos(x)`, `tan(x)` | 삼각함수 (x는 **라디안**) |
| `sqrt(x)` | 제곱근 |
| `pow(x, y)` | x의 y제곱 |
| `fabs(x)` | 실수의 절댓값 |
| `floor(x)`, `ceil(x)` | 내림, 올림 |
| `exp(x)`, `log(x)`, `log10(x)` | 지수, 자연로그, 상용로그 |

### 핵심 예제: 삼각함수 관계식 확인

`sin²θ + cos²θ = 1` 을 프로그램으로 확인한다.

- C언어의 삼각함수는 **도(degree)가 아니라 라디안(radian)** 을 사용한다.
- `radian = 3.141592 * degree / 180.0`
- 즉 60도는 `(3.141592 * 60) / 180`

```c
#include <stdio.h>
#include <math.h>
#define PI 3.141592

double rad(double degree)
{
    return PI * degree / 180.0;
}

int main(void)
{
    double x, y, result;
    x = sin(rad(60.0));
    y = cos(rad(60.0));
    result = x*x + y*y;
    printf("result=%f \n", result);
    return 0;
}
```
전체 소스: `06_trig_identity.c`

## 8. 실습: 자동차 게임

- 난수로 자동차 게임을 만든다.
- 사용자가 키를 누를 때마다 1초씩 주행한다.
- 주행 거리는 난수로 결정한다.

### 알고리즘
1. 난수 발생기를 초기화한다. (`srand`)
2. `for (i = 0; i < 주행시간; i++)`
   1. 난수를 발생시켜 자동차1의 주행거리에 누적
   2. 난수를 발생시켜 자동차2의 주행거리에 누적
   3. `disp_car()` 를 호출해 자동차1을 `*` 로 그린다.
   4. `disp_car()` 를 호출해 자동차2를 `*` 로 그린다.

### 핵심 포인트
- 난수 범위는 `%` 연산자로 0~99로 제한한다: `rand() % 100`
- 거리 10당 `*` 1개: `distance / 10` 번 반복
- `getch()` 는 키 입력을 기다린다. (`<conio.h>`, Windows/MSVC)

### 실행 결과 예
```
CAR #1:****
CAR #2:
---------------------
CAR #1:******
CAR #2:****
---------------------
```

## 9. 연습문제 (15장 복습)

**1. 올바른 함수 원형 정의가 아닌 것은?**
(가) `int funct(char x, char y);`
(나) `double funct(char x)`
(다) `void funct();`
(라) `char x();`

→ **정답: (나)** 원형은 세미콜론(`;`)으로 끝나야 하는데 (나)에는 없다.

**2. `int func(char x, float v, double t);` 의 반환값은?**
→ **정답: (나) int** — 함수 이름 앞의 자료형이 반환형이다.

**3. 올바른 함수 호출은?**
(가) `func;` (나) `func x, y;` (다) `func();` (라) `int func();`

→ **정답: (다)** 호출에는 괄호가 필요하고 자료형은 붙이지 않는다.

**4. 함수 전체를 올바르게 구현한 것은?**
(가) `int func();` (나) `int func(int x) {return x=x+1;}`
(다) `void func(int) {printf("Hello");` (라) `void func(x) {printf("Hello"); }`

→ **정답: (나)** (가)는 원형일 뿐 구현이 아니고, (다)는 `}` 가 빠졌고 매개변수 이름이 없다. (라)는 매개변수 자료형이 없다.

**5. `f(x, y) = 1.5*x + 3.0*y` 를 계산하는 함수를 작성하고 테스트하기**
