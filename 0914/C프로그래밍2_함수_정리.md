## 1. 함수의 개념

- **함수(function)**: 특정한 작업을 수행하는 독립적인 코드 부분
- **함수 호출(function call)**: 정의된 함수를 실제로 불러서 사용하는 것
- 함수는 **입력(매개변수)** 을 받아서 특정 작업을 수행하고 **출력(반환값)** 을 생성한다.
  - 예: `add()` 함수가 3과 7을 입력받아 10을 출력

---

## 2. 함수의 필요성

같은 코드가 반복되면 비효율적이다. 함수로 분리하면 한 번 정의된 코드를 여러 번 재사용할 수 있다.

### 함수 없이 작성한 경우 (반복 발생)
```c
#include <stdio.h>

int main(void)
{
    int i;

    printf("--------------------- \n");
    printf("--------------------- \n");

    for (i = 0; i < 5; i++)
        printf("%d의 제곱은 %d \n", i, i*i);

    printf("--------------------- \n");
    printf("--------------------- \n");

    return 0;
}
```

### 함수로 개선한 경우
```c
#include <stdio.h>

void print_lines()
{
    printf("--------------------- \n");
    printf("--------------------- \n");
}

int main(void)
{
    int i;

    print_lines();

    for (i = 0; i < 5; i++)
        printf("%d의 제곱은 %d \n", i, i*i);

    print_lines();

    return 0;
}
```
> 함수는 한 번 정의되면 여러 번 호출하여 실행할 수 있다.

**코드 설명**
| 코드 | 설명 |
|---|---|
| `void print_lines()` | 반환값이 없는(`void`) `print_lines`라는 이름의 함수를 정의. 구분선 두 줄을 출력하는 역할 |
| `int main(void)` | 프로그램이 시작되는 메인 함수. 매개변수 없음(`void`), 정수(`int`)를 반환 |
| `int i;` | 반복문에서 사용할 정수형 변수 `i`를 선언 (지역변수, `main` 안에서만 사용) |
| `print_lines();` | 위에서 정의한 `print_lines` 함수를 호출 → 구분선 출력 |
| `for (i = 0; i < 5; i++)` | `i`를 0부터 4까지 1씩 증가시키며 5번 반복 |
| `printf("%d의 제곱은 %d \n", i, i*i);` | `i`와 `i`의 제곱값(`i*i`)을 출력 |
| `return 0;` | `main` 함수가 정상 종료되었음을 운영체제에 알림 |

## 3. 함수를 이용하는 과정

1. **함수 정의**: 함수의 동작(코드)을 작성
2. **함수 호출**: `main()` 등 다른 곳에서 정의된 함수를 이름으로 불러서 실행

## 4. 함수의 정의

```c
반환형  함수이름( 매개변수 )
{
    함수의 몸체
}
```

예:
```c
void print_lines( void )
{
    printf("--------------------- \n");
    printf("--------------------- \n");
}
```

- **반환형**: 함수가 결과로 돌려주는 값의 자료형
- **함수의 이름**: 함수를 식별하는 이름
- **매개변수**: 함수가 외부에서 받는 입력값을 저장하는 변수
- **함수의 몸체**: 실제로 실행되는 코드 블록

---

## 5. 함수의 이름

함수 이름은 보통 **동사 + 명사** 형태로 짓는다.

```c
int    square(void)              // 정수를 제곱하는 함수
double compute_average(void)     // 평균을 구하는 함수
void   set_cursor_type(void)     // 커서의 타입을 설정하는 함수
```

---

## 6. 함수 호출

```c
int main(void)
{
    ...
    print_lines();   // 호출
    ...
    print_lines();   // 다시 호출
}

void print_lines(void)
{
    ...
}
```

호출 시 실행 흐름이 호출된 함수로 넘어갔다가, 함수 실행이 끝나면 다시 호출한 위치로 돌아온다.

## 7. 매개변수와 인수

- **매개변수(parameter)**: 함수 정의에서 외부의 데이터를 전달받기 위해 선언하는 변수. *형식 인수(형식 매개변수)*라고도 함
- **인수(argument)**: 함수를 호출할 때 실제로 전달하는 값. *실인수(실매개변수)*라고도 함

```c
int main(void)
{
    ...
    sum = add(2, 3);   // 2, 3 이 인수(argument)
    ...
}

int add(int x, int y)  // x, y 가 매개변수(parameter)
{
    ...
}
```

예시:
```c
int square(int n)                         // 정수를 제곱하는 함수
double compute_average(double x, double y) // 평균을 구하는 함수
void   get_cursor_type(void)               // 커서의 타입을 반환하는 함수
```
> 매개변수는 외부에서 전달되는 데이터가 저장되는 변수이다.

---

## 8. 반환값

- **반환값(return value)**: 호출된 함수가 작업의 결과를 호출한 곳으로 돌려주는 값
- **입력(인수)은 여러 개가 가능하지만, 출력(반환값)은 하나만 가능하다.**

```c
return 0;
return(0);
return x;
return x*x + 2*x + 1;
```

## 9. 함수 원형

- **함수 원형(function prototype)**: 함수를 실제로 정의하기 전에, 컴파일러에게 해당 함수의 반환형·이름·매개변수 정보를 미리 알려주는 선언문

### 형식
```c
반환형  함수이름(매개변수1, 매개변수2, ... );
```

예:
```c
int get_integer(void);
int combination(int n, int r);

// 매개변수 이름은 생략하고 자료형만 적어도 된다.
int get_integer(void);
int combination(int, int);
```

### 함수 원형을 사용하는 예
```c
int compute_sum(int n);   // 함수 원형 선언

int main(void)
{
    int sum;
    sum = compute_sum(100);
    printf("sum=%d \n", sum);
}

int compute_sum(int n)
{
    int i;
    int result = 0;
    for (i = 1; i <= n; i++)
        result += i;
    return result;
}
```

### 함수 원형을 사용하지 않는 예
함수의 **정의가 호출보다 먼저** 나오면 함수 원형이 없어도 컴파일된다. 다만 일반적으로 권장되는 방식은 아니다.

```c
int compute_sum(int n)   // 정의가 먼저 옴
{
    int i;
    int result = 0;
    for (i = 1; i <= n; i++)
        result += i;
    return result;
}

int main(void)
{
    int sum;
    sum = compute_sum(100);
    printf("sum=%d \n", sum);
}
```

## 10. 예제 모음

### 예제 1: 두 수를 더하는 함수 `add`
```c
#include <stdio.h>

int add(int x, int y)
{
    int result;
    result = x + y;
    return result;
}

int main(void)
{
    int sum;

    sum = add(2, 3);
    printf("덧셈 결과=%d \n", sum);

    sum = add(6, 8);
    printf("덧셈 결과=%d \n", sum);

    return 0;
}
```
실행결과
```
덧셈 결과=5
덧셈 결과=14
```

**코드 설명**
| 코드 | 설명 |
|---|---|
| `int add(int x, int y)` | 정수를 반환하는 `add` 함수. 매개변수 `x`, `y`는 호출할 때 전달받는 두 정수 |
| `int result;` | `add` 함수 안에서만 쓰이는 지역변수. `x + y`의 계산 결과를 임시로 저장 |
| `result = x + y;` | 매개변수 `x`와 `y`를 더해 `result`에 저장 |
| `return result;` | 계산된 `result` 값을 함수를 호출한 곳(`main`)으로 돌려줌 |
| `int sum;` | `main`의 지역변수. `add` 함수가 반환한 값을 저장 |
| `sum = add(2, 3);` | `add` 함수를 인수 2, 3으로 호출 → `x=2`, `y=3`이 되어 5를 반환받아 `sum`에 저장 |
| `printf("덧셈 결과=%d \n", sum);` | `sum`에 저장된 값을 출력 |
| `sum = add(6, 8);` | 같은 함수를 다른 인수(6, 8)로 재호출 → `sum`이 14로 갱신 |

### 예제 2: 정수의 제곱을 계산하는 함수 `square`
```c
#include <stdio.h>

int square(int n);

int main(void)
{
    int result;
    result = square(5);
    printf("%d ", result);
}

int square(int n)
{
    return (n * n);
}
```
`n`에 5가 들어가 `result`에 25가 저장된다.

**코드 설명**
| 코드 | 설명 |
|---|---|
| `int square(int n);` | 함수 원형(선언). `main`보다 아래에 정의되어 있어서 컴파일러에게 미리 알려주는 역할 |
| `int result;` | `main`의 지역변수. `square` 함수의 반환값을 저장 |
| `result = square(5);` | `square` 함수를 인수 5로 호출 → 매개변수 `n`에 5가 전달됨 |
| `printf("%d ", result);` | `result`(25)를 출력 |
| `int square(int n)` | 실제 함수 정의. 매개변수 `n`은 제곱할 대상 정수 |
| `return (n * n);` | `n`을 자기 자신과 곱한 값(제곱)을 반환 |

### 예제 3: 거듭제곱을 구하는 함수 `power`
```c
#include <stdio.h>

int power(int x, int y);

int main(void)
{
    int a, b, result;

    printf("두 개의 정수를 입력하시오: ");
    scanf("%d %d", &a, &b);

    result = power(a, b);
    printf("%d의 %d승은 %d입니다. \n", a, b, result);

    return 0;
}

int power(int x, int y)
{
    int i;
    int value = 1;          // 1로 초기화

    for (i = 0; i < y; i++)
        value *= x;          // value = value * x

    return value;
}
```
실행결과
```
두 개의 정수를 입력하시오: 2 3
2의 3승은 8입니다.
```

**코드 설명**
| 코드 | 설명 |
|---|---|
| `int power(int x, int y);` | 함수 원형. `x`의 `y`승을 계산하는 함수임을 미리 알림 |
| `int a, b, result;` | `main`의 지역변수. `a`=밑, `b`=지수, `result`=계산 결과 저장용 |
| `scanf("%d %d", &a, &b);` | 사용자가 입력한 두 정수를 `a`, `b`에 저장 (`&`는 변수의 주소를 넘겨 값을 채워 넣기 위함) |
| `result = power(a, b);` | `power` 함수를 `a`, `b`를 인수로 호출 |
| `int power(int x, int y)` | 매개변수 `x`(밑), `y`(지수)를 받는 함수 정의 |
| `int i;` | `power` 함수 안의 지역변수. `for`문의 반복 횟수를 세는 용도 |
| `int value = 1;` | 곱셈 결과를 누적할 변수. 곱셈이므로 1로 초기화(덧셈이면 0으로 초기화) |
| `for (i = 0; i < y; i++)` | `y`번(지수만큼) 반복 |
| `value *= x;` | `value = value * x`와 동일. `x`를 `value`에 반복해서 곱함 |
| `return value;` | 최종 거듭제곱 결과를 반환 |

### 예제 4: 두 수 중 큰 수를 찾는 함수 `get_larger`
> 핵심예제: 사용자가 입력한 2개의 정수 중에서 큰 수를 찾는 함수 `get_larger()`를 작성하고 테스트하라.

```c
#include <stdio.h>

int get_larger(int x, int y);

int main(void)
{
    int a, b;

    printf("두개의 정수를 입력하시오: ");
    scanf("%d %d", &a, &b);
    printf("두수 중에서 큰 수는 %d입니다.\n", get_larger(a, b));

    return 0;
}

int get_larger(int x, int y)
{
    if (x > y) return (x);
    else       return (y);
}
```
실행결과
```
두개의 정수를 입력하시오: 3 8
두수 중에서 큰 수는 8입니다.
```

**코드 설명**
| 코드 | 설명 |
|---|---|
| `int get_larger(int x, int y);` | 함수 원형. 두 정수 중 큰 값을 반환하는 함수임을 선언 |
| `int a, b;` | `main`의 지역변수. 사용자가 입력한 두 정수를 저장 |
| `printf("두수 중에서 큰 수는 %d입니다.\n", get_larger(a, b));` | `printf` 안에서 바로 `get_larger(a, b)`를 호출하여 반환값을 곧바로 출력 (별도 변수에 저장하지 않고 함수 호출 결과를 바로 사용하는 예) |
| `int get_larger(int x, int y)` | 매개변수 `x`, `y`로 비교할 두 정수를 받음 |
| `if (x > y) return (x);` | `x`가 `y`보다 크면 `x`를 반환하고 함수 종료 |
| `else return (y);` | 그렇지 않으면(`y`가 크거나 같으면) `y`를 반환 |

### 예제 5: 소수(prime) 판별 실습
- 주어진 숫자가 소수(prime)인지 판별하는 프로그램
- 양의 정수 n이 소수가 되려면 1과 자기 자신만을 약수로 가져야 한다.
- 소수는 암호학에서 많이 사용된다.

**알고리즘**
1. 사용자로부터 정수를 입력받아 변수 `n`에 저장한다.
2. `for (i = 2; i < n; i++)` 반복하면서 `n`을 `i`로 나누어 나머지가 0인지 확인한다.
3. 나머지가 0인 경우가 한 번이라도 있으면 소수가 아니다.

```c
#include <stdio.h>

int is_prime(int);
int get_integer(void);

int main(void)
{
    int n, result;

    n = get_integer();
    result = is_prime(n);

    if (result == 1)
        printf("%d은 소수입니다.\n", n);
    else
        printf("%d은 소수가 아닙니다.\n", n);

    return 0;
}

int get_integer(void)
{
    int n;
    printf("정수를 입력하시오: ");
    scanf("%d", &n);
    return n;
}

int is_prime(int n)
{
    int i;
    for (i = 2; i < n; i++)
    {
        if (n % i == 0)
            return 0;
    }
    return 1;
}
```
실행결과
```
정수를 입력하시오: 21
21은 소수가 아닙니다.
```

**코드 설명**
| 코드 | 설명 |
|---|---|
| `int is_prime(int);` | 함수 원형. 정수 하나를 받아 소수인지 판별(1이면 소수, 0이면 소수 아님)하는 함수 선언 |
| `int get_integer(void);` | 함수 원형. 매개변수 없이 사용자 입력을 받아 정수를 반환하는 함수 선언 |
| `int n, result;` | `main`의 지역변수. `n`=판별할 정수, `result`=`is_prime`의 반환값(1 또는 0) |
| `n = get_integer();` | `get_integer` 함수를 호출해 사용자 입력값을 `n`에 저장 |
| `result = is_prime(n);` | `n`을 인수로 `is_prime` 함수를 호출해 소수 여부를 `result`에 저장 |
| `if (result == 1) ... else ...` | `result` 값에 따라 소수/비소수 메시지를 출력 |
| `int n;` (get_integer 내부) | `get_integer` 함수만의 지역변수. `main`의 `n`과 이름은 같지만 서로 다른 변수(지역변수는 함수마다 독립적) |
| `scanf("%d", &n);` | 키보드로 입력받은 정수를 `n`에 저장 |
| `return n;` | 입력받은 정수를 호출한 곳(`main`)으로 반환 |
| `int i;` (is_prime 내부) | 2부터 `n-1`까지 나누어볼 값을 저장하는 지역변수 |
| `for (i = 2; i < n; i++)` | `i`를 2부터 `n-1`까지 증가시키며 반복 |
| `if (n % i == 0) return 0;` | `n`이 `i`로 나누어떨어지면(나머지 0) 1과 자기 자신 외의 약수가 있다는 뜻이므로 소수가 아님(0)을 즉시 반환 |
| `return 1;` | 반복문을 끝까지 돌면서 나누어떨어지는 경우가 없었다면 소수(1)를 반환 |

## 11. 실습 문제

### 초기값과 끝값까지 더하기
- 사용자로부터 정수인 **초기값**과 **끝값**을 입력받는다.
- 예: 0과 10을 입력하면 결과는 **55**가 나와야 한다.
- 예: 9와 10을 입력하면 결과는 **19**가 나와야 한다.
- 함수 내에 반복문(for/while)을 사용하여 합계를 구하도록 구현한다.

> 원본 자료에는 문제 설명만 제시되어 있으며, 정답 코드는 포함되어 있지 않다. 아래는 힌트다.
> - 함수 원형 예: `int sum_range(int start, int end);`
> - 함수 내부에서 `for (i = start; i <= end; i++) total += i;` 형태로 구현하면 된다.
